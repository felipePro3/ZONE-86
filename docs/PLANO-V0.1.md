
# ZONE-86 — Planejamento da versão 0.1

## Conceito
ZONE-86 é um jogo de sobrevivência e exploração no Roblox, ambientado em uma zona de exclusão fictícia.

O jogador começa em uma base segura, recebe missões, explora uma cidade abandonada e descobre os mistérios de uma usina fictícia e de uma instalação subterrânea de contenção.

## Mapa inicial
- Base segura: ponto inicial, NPC de missões e futura loja.
- Cidade abandonada: ruas, prédios e locais para explorar.
- Usina fictícia: cenário para missões futuras.
- Instalação subterrânea: área de ficção científica com portas de acesso.
- Zona contaminada: área com perigo ambiental fictício.

Tamanho inicial sugerido: aproximadamente 512 × 512 studs. Ajustar depois dos primeiros testes.

## Primeira versão jogável
1. Criar a base e o ponto inicial do jogador.
2. Construir uma pequena área explorável.
3. Adicionar uma zona de radiação fictícia.
4. Testar o sistema de dano nessa zona.
5. Criar uma missão simples de exploração e retorno à base.

## Ideias para versões futuras
Inventário, fome, sede, créditos, equipes, cartões de acesso, clima e salvamento de progresso.

Esses sistemas ainda não estão implementados.
